KOTOR FUNKYDATA EDITION

- Comparateur de Screenshots JS
  - https://funkydata13.github.io/kotor_fde/comparateur.html?id=0

- DelDuplicateTGA-TPC.bat
  - Script terminal qui supprime au choix les TPC ou les TGA/TXI s'il trouve la même texture dans les deux formats dans le dossier "override"

- kotor_mode_backup.bat
  - Clone ou fusionne les dossiers "override" et "modules", au choix, dans un backup ou depuis le backup. Indispensable pour rollback si un ou plusieurs mods ont foirés.
  - Gère également le backup/la restauration de l'exe en cas de patch UI ou mémoire
  - Gère également le backup/la restauration du fichier de dialogue "dialog.tlk"
  - Gère également le backup/la restauration du preset Reshade
